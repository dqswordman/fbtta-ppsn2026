# Paper Link Insertion

Use the following sentences in the PPSN paper once the public URLs are available.

## Code repository

`Code for the PPSN 2026 submission snapshot is available at <REPO_URL>.`

## Release snapshot

`The versioned public release used for this submission snapshot is available at <RELEASE_URL>.`

## Future supplement DOI placeholder

`An archived online supplement with the submission snapshot materials is available at <SUPPLEMENT_DOI_OR_URL>.`
